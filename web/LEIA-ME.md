# Tela (frontend) – Viver Bem Saúde

React + TypeScript + Vite + Ant Design.

## Requisitos
- Node.js 20 ou mais novo (`node --version`).
- Servidor rodando em http://localhost:5000 (`dotnet run` em `src/VBS.Agendamento.Api`).

## Como rodar
    npm install
    npm run dev

Abra http://localhost:5173. O Vite repassa `/api` para o servidor, então não há problema de CORS.

## Conferir antes de entregar
`npm run build` confere os tipos do TypeScript e gera a versão de produção.

Veja o [README](../README.md) e o [ARCHITECTURE.md](../ARCHITECTURE.md) na raiz do repositório.
